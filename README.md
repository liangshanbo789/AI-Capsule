## 🛠️ 如何将本项目部署至您自己的 GitHub Pages？

如果您想搭建自己的推广页，本项目采用纯前端（HTML + CSS + JS）编写，极其易于部署：

1. **Fork** 本项目至您自己的 GitHub 账号下。
2. 进入您的仓库设置：`Settings` -> `Pages`。
3. 在 **Build and deployment** 下选择 `Deploy from a branch`。
4. 将 `Branch` 设为 `main` 并指向 `/ (root)`，点击 `Save`。
5. 等待几分钟，即可生成您专属的推广展示静态网页！
6. *别忘了在 `index.html` 中将商城跳转链接替换为您自己的推广链接哦！*
